RETRO 1.4 - Le coin du vieux nostalgique (Projet Padawan)
=======================================================
Lanceur Commodore 64 / MS-DOS / Windows 98, avec bibliotheque, pochettes et ecran « READY. ».

EMULATEURS (installes A LA DEMANDE, depuis les sources officielles)
  Commodore 64 : VICE       https://vice-emu.sourceforge.io/   (versions GitHub de l'equipe VICE)
  MS-DOS       : DOSBox-X   https://dosbox-x.com/              (GitHub joncampbell123, sinon winget)
  Windows 98   : 86Box      https://86box.net/                 (GitHub 86Box)
  Installes dans C:\web_private\retro\emulateurs (sans C:\web : %LOCALAPPDATA%\Padawan\Retro).

BIBLIOTHEQUE
  - Glisse tes fichiers dans la fenetre (ou « + Ajouter ») :
      C64 : .d64 .d71 .d81 .g64 .prg .t64 .tap .crt
      DOS : .exe .com .bat, un dossier de jeu (« + Dossier DOS », monte en C:), .img/.ima (disquette A:),
            .iso/.cue (CD en D:), .vhd (disque dur)
      Win98 : « + Machine Win98 » cree une machine 86Box ; insere ton CD/ISO Windows 98 par le menu Media d'86Box.
  - Double-clic ou Entree = lancer. Clic droit = renommer, pochette, systeme, favori, ouvrir le dossier, retirer.
  - Pochettes : la tienne (png/jpg/gif) ou une pochette generee automatiquement facon boite des annees 80.
  - Donnees : Documents\Padawan\Retro (bibliotheque.json, pochettes, machines_win98).

AMBIANCE
  Ecran C64 « READY. » anime au demarrage (clic ou Echap pour passer), bandes de chargement,
  petits bruits de lecteur de disquette, themes C64 / DOS / Norton (bouton Theme ou F9).
  F1 Aide, F2 Renommer, F3 Pochette, F4 Systeme, F5 Lancer, F6 Favori, F7 Ajouter, F8 Retirer, F9 Theme, F10 Quitter.

LEGALITE
  Aucun ROM, jeu ni systeme protege n'est inclus. Tu fournis tes propres jeux, ton CD Windows 98
  et les ROMs BIOS d'86Box. Bouton « Sources legales » : CSDb, itch.io (homebrew C64/DOS),
  Classic DOS Games, DOS Games Archive, FreeDOS, GOG, documentation ROMs 86Box, CD shareware (archive.org).

LIMITES
  - 86Box : la machine se configure dans ses propres reglages (premier lancement) ; il lui faut des ROMs BIOS.
  - Sans Internet, l'installation des emulateurs est reportee ; la bibliotheque fonctionne toujours.

    Canadien français / Américain (US) / France (AZERTY).
  - Super Star Trek (et Animal, Le Pendu) : la conversion pour bwBASIC coupait STOP en « S TO P » → le jeu

  - Les jeux de 1978 attendent des MAJUSCULES : les réponses tapées en minuscules (srs, nav, oui…) sont
    maintenant acceptées (UCASE$ ajouté après chaque INPUT de texte des listings DOS).

  ton clavier à droite (écran bleu comme EDIT). Chaque ligne est vérifiée quand tu fais Entrée (vert = bon,
  rouge = faute), F5 vérifie tout, compteur de caractères/minute. « ▶ Lancer dans DOS » enregistre dans
  C:\MESPROGS et lance ton programme avec RUNBAS.

POURQUOI PAS QBASIC, QB45, GW-BASIC, PKZIP, THEDRAW ?
  QBasic, QuickBASIC 4.5 et GW-BASIC appartiennent à Microsoft : ils ne sont PAS libres de redistribution
  (les sites « abandonware » n'ont aucun droit de les donner). PKZIP est un shareware commercial (PKWARE),
  et TheDraw n'a jamais été publié sous une licence claire de libre redistribution. Rétro les remplace par :
    QBasic/GW-BASIC → Bywater BASIC 3.30 (interpréteur, GPL v2)
    QB45 (compilateur) → FreeBASIC 1.10 pour DOS, option -lang qb (GPL v2)   [commande QB]
    PKZIP/PKUNZIP → Info-ZIP ZIP 3.0 / UNZIP 6.0 (licence Info-ZIP), 7-Zip DOS, ARJ libre
    Norton Commander → Volkov Commander 4.99 (BSD 2 clauses), Dos Navigator 2 (open source)
    ANSI.SYS → NANSI.SYS (GPL v2) ; DOSBox-X interprète aussi l'ANSI tout seul ; ANSiMat pour voir l'art ANSI
  Si tu possèdes TON QBASIC.EXE (vieux CD MS-DOS/Windows 95), menu Atelier → « Utiliser mon propre QBASIC.EXE ».

=== RÉTRO 1.4 - SUITE : GW-BASIC, PASCAL, C, LIBRAIRIES, IMPORT/EXPORT ===
LE VRAI GW-BASIC (légal !)
  En 2020, Microsoft a publié le code source de GW-BASIC sous licence MIT (github.com/microsoft/GW-BASIC).
  Rétro installe GWBASIC.EXE assemblé depuis ce code par le projet communautaire tkchia/GW-BASIC
  (codeberg.org/tkchia/GW-BASIC, version 20261005, commit 1432e385). Forge a reconstruit ce dépôt
  lui-même avec JWasm/JWlink : les .EXE sont identiques octet pour octet à la version publiée.
  Rétro vérifie l'empreinte SHA-256 avant de les installer.
    GWBASIC.EXE  ceb0c57c1c31981844a2e41b375cd14f77630e3e200419fe746b501d21dcf333
    GWBASICA.EXE 1a7b92b1aaf893e7f040190b8fa728e3c5b4dd82caaded8fefd0a471f669f7f7 (expérimental : TIMER, MKDIR…)
  Dans l'atelier : C:\GWBASIC (LICENSE.TXT = licence MIT, SOURCE.TXT = provenance). Menu G, RUNGW NOM.
  Limites : pas de port série (COM), et le crayon optique, la manette et l'imprimante sont peu testés.
  Les vieux jeux attendent des MAJUSCULES : Rétro active Verr. Maj avant de lancer GW-BASIC.
  ⚙ Options → « BASIC DOS » : GW-BASIC (par défaut) ou bwBASIC (qui accepte aussi les minuscules).
  Les fichiers GW-BASIC enregistrés en binaire (SAVE sans ,A) s'ouvrent toujours dans GW-BASIC.
  MS-DOS 4.0 (MIT) : pas ajouté. DOSBox-X fournit déjà les commandes DOS, et FreeDOS couvre les outils
  utiles. Pour s'en servir, il faudrait construire une disquette et démarrer dessus, ce qui demande beaucoup
  de travail pour presque rien de nouveau (les sources de 4.0 servent surtout à étudier le code).

PASCAL ET C  (menu Atelier → « Installer Pascal et C », ≈150 Mo à télécharger, ≈200 Mo sur le disque)
  Free Pascal 3.2.2 (GPL v2) : TP NOM.PAS = IDE plein écran fp, comme Turbo Pascal 7 (F9 compiler,
  Ctrl+F9 exécuter, Alt+X quitter). PASC NOM = compile en ligne. Unités CRT, GRAPH, DOS incluses.
  DJGPP 2.05 + GCC 12.2 + RHIDE 1.5 (GPL) : TC NOM.C = IDE comme Turbo C. CC NOM = compile en ligne.
  Exemples : C:\MESPROGS\PASCAL\BONJOUR.PAS et C:\MESPROGS\C\bonjour.c (compilés et testés).
  Pour la taille, Rétro n'installe pas les sources, LTO, gdb, les traductions ni les docs info.
  Les sources sont sur les dépôts FreeDOS (fd.lod.bz / ibiblio.org).
  Turbo Pascal et Turbo C de Borland ne sont PAS fournis : ce sont des logiciels commerciaux, et les
  versions « gratuites » d'Embarcadero ne permettaient pas de les redonner. Si tu as les tiens (tes
  disquettes), importe-les : ils iront dans C:\PERSO (voir plus bas).

LIBRAIRIES (C:\LIBS, chacune avec un exemple compilé et testé)

         VGA13H.H, mini-librairie VGA 320x200 + souris écrite pour Rétro (MIT) : CC VGADEMO

📥 IMPORTER MES VIEUX TRUCS  (bouton 📥 Importer, menu Atelier, glisser-déposer)
  Accepte un dossier, des fichiers ou un .zip : .BAS (texte ou GW-BASIC binaire), .prg, .d64, .t64,
  .com/.exe, .txt de listings. Rétro COPIE (tes originaux ne bougent jamais) vers
  C:\web_private\retro\atelier\mes_programmes\c64 ou \dos, convertit l'encodage (UTF-8 → page 437)
  et les fins de ligne (CR/LF), et devine C64 ou DOS (POKE 53280, {CLR}… = C64 ; CLS, COLOR, LOCATE… = DOS).
  Un listing C64 en texte devient un .prg. Tout arrive dans la collection « Mes vieux trucs » :
  double-clic pour lancer, clic droit → ✎ Modifier la fiche (titre, notes).
📤 EXPORTER (clic droit sur une fiche) : .zip (fichier + fiche), .bas texte, .prg ou disquette .d64.

DOSSIER PRIVÉ C:\PERSO  (atelier\dos\PERSO)
  Les logiciels d'époque que tu importes (.EXE/.COM, ex. QB45 de tes disquettes) vont dans C:\PERSO.
  Ce dossier est dans le PATH, et un lanceur NOM.BAT est créé pour chaque programme.
  Ce dossier est PRIVÉ : il contient le marqueur _PRIVE_NE_PAS_DISTRIBUER.TXT et doit être EXCLU
  du zip, de l'exe d'installation et de toute copie pour les collègues.
